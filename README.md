# Job Application Tracker

A platform for tracking job applications, interviews, application status, and career progress.

## Tech Stack

### Backend
- Java
- Spring Boot
- Spring Data JPA
- Spring Security
- JWT
- Maven

### Frontend
- React
- JavaScript
- HTML
- CSS

### Database
- PostgreSQL

### DevOps
- Git
- GitHub
- Docker
- Docker Compose
- GitHub Actions

### Testing
- JUnit
- Mockito
- Spring Boot Testing
- React Testing
